# 企业管理台账

### 1. 触发

走访前查阅企业档案，收到企业资料或批量表格时更新台账。

### 2. 使用者与确认人

有企业应用操作权限的经办人员维护台账。外部协作者可以查询和导出脱敏数据。

### 3. 输入

新建企业必填 name。批量导入接受 rows 数组或带字段名表头的 UTF-8 CSV。复合字段使用 JSON。

### 4. 处理步骤

应用检查权限、字段和重名，再保存私库原值及 core 脱敏版本。部署时将环境变量
`JKQ_ENTERPRISE_PRIVATE_DB` 指向仓库外的 SQLite 绝对路径，父目录仅开放给服务账号。
备份时一并保留私库和 core 数据。

### 5. 确认依据

经办人员在详情中核对版本的修改人、修改时间和前后值。批量导入按错误行号和原因修正后可单独重试。

### 6. 输出

查询返回匹配企业和筛选项。详情展示走访、诉求、文件、待确认建议及历史。导出支持按企业 ID 选择，敏感值打码，可能触发公式的单元格按文本输出。

### 7. 验收样本

运行 `python3 -m pytest -q apps/enterprise/tests`。用例使用虚构企业测试中文、多行 CSV、并发重名、权限、历史及千行导入。
