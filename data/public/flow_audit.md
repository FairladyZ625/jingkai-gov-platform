## P0｜对话和右侧面板串台（就是截图里"星河智驾 17 项 / 芯视界 14 项"那个问题）

**复现步骤**（已复现，截图 `flow_bug_conv_switch.png`）：
1. 问"帮我查一下星河智驾能申报哪些政策"，对话显示"星河智驾：17 项可进一步核对"。
2. 点"新对话"，再问"芯视界半导体能申报哪些政策"。
3. 在左侧"最近对话"点回第一条对话。

**结果**：左边对话写的是"星河智驾：17 项"，右边政策兑现面板仍然是"芯视界半导体：14 项可核对"。

**根因**：每条对话只保存了消息，没有保存"这条对话当时右侧打开的应用和对象"。各应用（policy 等）又是全局单例，状态 `S.entId` 一直停在最后一次操作上。
- `assets/shell.js:268` `function openConv(id) { S.cur = id; ensureChatVisible(); renderSide(); renderChatBody(); }`：切换对话时只重绘聊天，不重置、不恢复面板。
- `assets/shell.js:267` `newChat()` 同样不清面板。
- `apps/policy/app.js:42`：`const S = { … entId: null … }` 是挂载级别的状态，和对话无关。

**修复建议**：在 `runIntent` 或操作员 `done()` 时，往当前对话里写一份 `conv.panel = { app, route, params: { entId } }`。`openConv` 时如果有 `conv.panel`，就调用 `openApp(app, route, params)` 恢复；没有的话，至少在面板顶部提示"右侧显示的是：芯视界半导体（来自另一条对话）"。`newChat()` 时把各应用 `go('home')` 复位。

## P0｜跨应用"带上企业和政策"首次打开时会丢参数

**复现步骤**（截图 `flow_bug_todoc_lost.png`）：依次说"帮我查一下星河智驾能申报哪些政策"→"给星河智驾生成政策告知单"→"把告知单转成公文答复"。

**结果**：对话里说"已带上企业和政策依据，打开公文协作（答复意见）"，但公文协作停在第 1 步"要办什么事？"，模板 T10、企业、政策、告知单都没带过去。

**根因**：`assets/shell.js:206-210` `openApp()` 只在应用**已经挂载**的情况下调用 `slot.ctl.go(route, params)`（`else if (route || params) {… go(...) }`）。首次挂载时只把 params 塞进 `makeCtx(id, el, params)`，而 `apps/document/app.js`、`policy`、`enterprise`、`meeting` 的 `mount()` 都不读 `ctx.params`（只有 kb、skills、computer 读）。所以政策→公文、会议→企业、政策 toast"查看"→企业诉求这几条首次跳转都会丢上下文。

**修复**：在 `openApp` 挂载后补一句 `if (fresh && route) slot.ctl.go && slot.ctl.go(route, params||{})`；或者让四个业务应用在 `mount` 末尾 `if (ctx.params && ctx.params.route) go(ctx.params.route, ctx.params)`。
