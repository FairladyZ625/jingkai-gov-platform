# 一键演示回归

在仓库根目录进入 `tests/demo`。首次用 Node.js 18+ 安装锁定的依赖与 Chromium。

```sh
cd tests/demo
npm ci
npx playwright install chromium
npm test
```

以后在此目录运行 `npm test` 即可。脚本用断网的 Chromium 打开 `prototype/v4/index.html`，从王敏演示账号点击侧栏「一键演示」。1440×900、1280×900 各从深色和浅色启动一次，四组浏览器上下文相互独立。第 12 段按脚本切换浅色，再恢复深色。

每段在运行期间核对可见结果与业务回执，并监听页面异常、控制台错误和演示引擎警告。公文段记录本次创建的文稿和送审单 ID，审签段核对李阳处理同一审签单且对应文稿已定稿。协作者段复查王敏与何军看到的同一企业档案，核对联系人电话和营收脱敏。企业通过模拟数据的稳定 ID 定位。

两个 P0 从干净会话复现。切回历史会话后核对政策面板的企业，首次进入公文时核对模板、企业 ID 和告知单首项政策 ID。PR #59 合入前，只有这两个已知故障的具体表现计为「预期失败」。其它错误或预期失败用例意外通过时退出码为 1。PR #59 合入后，移除 `run.cjs` 中相应的 `expectedFailures` 标记并复跑。

每次运行重写 [REPORT.md](REPORT.md)。报告列出各段结果、业务证据及截图。初始化失败时报告本次失败和未执行段落。演示段和非预期失败决定退出码。截图供人工核对布局。验证范围为离线 mock 原型。
