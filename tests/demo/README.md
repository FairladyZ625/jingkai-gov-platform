# 一键演示回归

从仓库根目录进入测试目录，首次安装 Node.js 18+ 对应依赖及 Chromium。

```sh
cd tests/demo
npm ci
npx playwright install chromium
npm test
```

以后在此目录运行 `npm test` 即可。脚本用断网的 Chromium 打开原型的本地文件，点击王敏演示账号和侧栏「一键演示」。1440×900、1280×900 各用深浅两种起始主题走一遍，每次使用独立浏览器上下文。第 12 段按原型脚本切换主题。

每段按配置顺序核对可见业务文字，监听未捕获异常、控制台错误及演示引擎的异常警告，并保存当前窗口截图。两条独立 P0 用例从新会话开始，使用聊天输入框复现审计路径，检查切回会话后的企业以及首次进入公文时的模板、企业和政策依据。

每次运行重写 [REPORT.md](REPORT.md) 和对应截图。全部通过时退出码为 0；任一段落或 P0 断言失败时退出码为 1。P0 修复后原样重跑即可验证。截图供人工核对布局，脚本没有像素差异基准。此报告覆盖离线 mock 原型，公网真后端验收另行记录。
