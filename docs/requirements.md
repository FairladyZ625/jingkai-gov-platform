# 经开区共享智能体工作站需求

依据公开的[开发计划与任务拆分](plan/开发计划与任务拆分.md)整理。平台接口见[接口规范 v1.3](接口规范.md)，前端模块边界见[应用契约](APP_CONTRACT.md)。

## 工作台与演示

- 以对话作为工作入口。经办人员能输入要办的事、上传附件、打开业务应用，并在对话中查看执行进度、结果和依据。
- 政策兑现、企业管理、会议记录、公文协作共用工作台。应用间传递企业、政策、文稿等记录标识，切换对话后恢复对应面板和状态。
- 静态原型默认使用本地模拟数据与接口，可离线打开，也可通过 HTTP 从站点根路径或子路径访问。一键演示包含 12 段，用于检查典型业务流程、角色切换和主题。

## 平台能力

- 支持经办人员、审签领导、管理员、外部协作者四类角色。服务端依据角色、应用和动作判定权限，外部协作者只能看到授权范围内的数据，受限字段需要脱敏。
- 对话历史和面板状态可恢复。模型网关统一提供模型列表、工具调用和流式响应，依据数据密级限制出域。演示环境支持模拟模型。
- 长任务可查询进度并在服务恢复后续跑。需要人确认的操作生成待办或审签单，审签绑定具体版本，提交人不能审自己的，关键操作写入审计日志。
- 知识库支持按空间授权、导入、检索与问答。回答指明引用出处，缺少依据时明确提示。

## 业务应用

| 应用 | 用户可完成的工作 |
|---|---|
| 政策兑现 | 查询事项，按企业画像匹配条件，查看依据并生成政策告知单 |
| 企业管理 | 维护一企一档，整理走访记录，逐条确认台账更新建议，追踪企业诉求与提醒 |
| 会议记录 | 上传录音、转写、整理发言人与纪要、派发待办，并关联企业诉求 |
| 公文协作 | 按模板起草，核查与修订，比对历史版本，送审、锁定定稿并导出 |

## 技能与电脑操作

- 技能支持创建、试运行、发布和上架审核。运行时只调用技能声明的工具。
- 电脑操作演示使用模拟政务站。遇到提交、签章或验证码时暂停，由人员确认后再继续。
- 演示数据可重置。引用公开政策文号的数据须能追溯原文，虚构企业须标明为示例。

## 交付阶段

| 阶段 | 验收重点 |
|---|---|
| M0 仓库与原型就位 | 静态迁移、离线模拟、演示回归与公开数据溯源 |
| M1 平台底座 | 登录授权、网关、应用注册、长任务与审签接口 |
| M2 对话与知识库 | 对话恢复、知识库空间授权、检索与带出处问答 |
| M3 四个业务应用 | 应用接入后端、跨应用链路及关键写操作确认 |
| M4 技能与联调 | 技能上架、模拟政务操作、演示稳定性和主题回归 |
