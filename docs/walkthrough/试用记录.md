## 复跑

使用 Node.js 18+，在仓库根目录执行。新建输出目录便于区分不同轮次的图片。

```sh
npm ci --prefix tests/demo
(cd tests/demo && npx --no-install playwright install chromium)
NODE_PATH="$PWD/tests/demo/node_modules" node tests/walkthrough/run.cjs /tmp/jkq-walkthrough
```

如只复查一组，可在输出目录后追加组合名，例如 `1280-dark`。默认依次运行四组，避免多个标签页同时取景。

pytest CI 通过 `tests/walkthrough/test_walkthrough.py` 运行同一个脚本，核对现场图片清单与提交的截图，并检查 15 MB 总量上限。截图核对范围为 900 px 视口高度下的演示页面；公网与真后端待 #50 合并后复测。

## 验收范围

本 PR 只做离线 mock 走查与截图回归：`run.cjs` 以 `file://` 打开原型、断网，并断言 `api.mode` 为 `mock`；复用的 `tests/demo/checks.cjs` 读取浏览器 mock 的内部状态，不能直接用于真实后端。真后端验收以 #138 的 `tests/demo_http/browser_acceptance.py` 为准，其以 HTTP 业务回执判定 12 段，并要求全程不触发 mock 请求。

全部截图已按合入主线 12407e7 后的原型用 `run.cjs` 重新采集，已反映 05f1446 起侧栏开发计划入口默认隐藏。

## 已知限制（真后端一键演示）

- 技能中心：技能试运行在无模型演示配置下报“暂无可处理该密级的模型”。演示不放宽密级路由，起草出预置草稿后即结束该步，试运行之后的分享与发布步骤演示时跳过（`prototype/v4/apps/skills/app.js` 的一键演示在试运行失败时以“已起草……演示时跳过”收尾；mock 离线模式试运行成功，流程不变）。因此 `tests/demo_http/browser_acceptance.py` 在技能中心段仍会报“缺少 HTTP 业务回执”（share/publish），该断言保持不变。
- 知识库网址导入：演示环境不访问外网，也不为官网样例网址配置本地快照；网址导不进来时后端返回 502 并给出中文提示（如“演示环境不访问外网，请改用粘贴正文”），演示时改用粘贴正文或上传文件。后端的 502 转换与来源标签由 codex/kb-import-fix 修复，合入前公文段开头的知识库导入仍可能因来源标签校验返回 422。
- 技能中心“用同事的技能”：真后端尚无“实体书店政策预判”等同事技能种子（依赖 #118 合入后的技能种子），会提示没找到对应的技能。
