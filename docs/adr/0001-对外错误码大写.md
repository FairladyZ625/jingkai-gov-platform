# ADR 0001　对外错误码统一使用大写 SNAKE_CASE

Issue #130 将 HTTP 错误信封的 `error.code` 统一为大写，与经开区接口规范一致。SDK 1.0 客户端若逐字比较 `version_conflict`，升级后将跳过冲突恢复，因此 Python 和 JavaScript SDK 同升至 2.0.0。客户端应将判断值更新为 `VERSION_CONFLICT`，中文提示查找兼容旧码。

HTTP 状态、消息、重试标志和错误详情沿用原语义。服务内部仍可按小写分类。随实现更新 v1 夹具及公共面快照，由 CEO 在演示后合并前完成 CODEOWNERS 评审。
