# 经开智能体工作站 v4 · 设计规范 2.0（冻结）
> 2026-11-18 重做。风格**完全参考 multica.ai**（研究资料：`/workspace/jk/style_ref/multica/notes.md` + 截图）。
> 唯一来源：`assets/theme.css`（令牌）+ `assets/ui.css`（组件）+ `assets/shell.css`（外壳）。应用不写死任何色值。

## 1. 原则
1. **白底默认**：首次打开、登录页一律浅色；深色是可选项（右下角头像旁 ☾/☀ 或设置）。
2. **灰阶做层级，颜色只做编码**：90% 的层级靠黑 / 灰两级文字、字号、字重、发丝线。彩色只出现在 **7px 圆点、图标、细边** 上。
3. **黑色主按钮**：一个视图最多一个 `.btn.primary`（浅色主题黑底白字，深色主题浅底黑字）。品牌蓝 `--accent` 只用于链接、进度、选中描边、徽标数、焦点光标，**不做大面积填充**。
4. **轻字大标题**：大标题用 400 字重 + 负字距（`.display` / 首页问候 36px），应用内标题 20px/500，卡片标题 14px/600。
5. **少字**：卡片标题 ≤14 字；说明 ≤1 行；回答首屏 ≤4 行；按钮 2–4 字。
6. **不花**：同屏彩色圆点类别 ≤4 种；不用渐变、不用彩色大底、不用粗边框；阴影只有 3 档。

## 3. 语义色板（11 色相，各类标签固定颜色）
色相：gray blue indigo violet pink red orange amber green teal cyan；每个色相有 `--t-<hue>-fg / -bg / -bd`，浅深两套分别调过（浅色：600 级饱和度；深色：400 级 + 12% 透明底）。
- **默认标签 `.tag`** = 白底 + 1px 边 + **彩色圆点** + 黑字（multica 胶囊）。
- `.tag.soft` = 淡色底 + 同色字（需要更醒目时，如“必须改”）。`.tag.plain` = 只有圆点 + 灰字。
- 状态语义固定：灰 = 草稿/未开始，蓝 = 进行中，琥珀 = 待确认/待处理，绿 = 完成/有效，红 = 错误/退回。
- 映射表在 `config/tags.js`（文种、政策类别、状态、优先级、角色、知识库空间、模型提供方…），`JK.tag(label, group)` 自动取色。
- **应用身份色**：只用在应用图标的线条颜色上（图标块为白底细边）：政策 indigo / 企业 teal / 会议 violet / 公文 orange / 知识库 cyan / 技能 pink / 电脑 amber。

## 5. 组件规则（类名见 REDESIGN_NOTES.md）
- 按钮：默认白底细边 + 微阴影；`.primary` 黑；`.ghost` 透明灰字；`.soft` 浅灰底；`.brand` 蓝（极少用，仅“AI 正在操作”类提示）；`.pill` 胶囊（对话里的下一步建议）。
- 菜单 / 下拉：项自适应高度，**两行**（`.mi-t` 标题 14→13px / `.mi-d` 灰色说明 12px，各自单行省略），右侧 `.mi-r` 放胶囊 / 勾选；分组标题 `.mh` 12px 灰，组间发丝线。
- 标签页 `.tabs`：13px 灰字，选中黑字 + 2px **黑色**下划线。分段 `.seg`：浅灰胶囊容器，选中白底。
- 卡片 `.card`：白底、1px #E4E4E7、10px 圆角、`--shadow-1`；看板 / 分组底用 `.card.ghost`（#FBFBFB）。
- 表格 `.tbl`：灰色 12px 表头 + 行间发丝线（changelog 式），行高 40。
- 向导 `.wiz-steps`：当前步黑色实心圆，已完成浅灰圆 + 勾，连线灰。
- 任务清单 `.plan`：完成 = 黑色实心勾，进行中 = 蓝色转圈，待确认 = 琥珀圆；人工决策卡 = 浅灰底 + 左侧 3px 琥珀条。
- 弹窗 `.modal` / 抽屉 `.drawer`：浮层白底、12px 圆角、`--shadow-pop`；抽屉离屏幕边 8px。底栏浅灰底。
- 轻提示 `.toast`：**深色浮条**（两种主题都是深色），左侧状态点。
- 引用 `.cite`：灰色小方块角标，悬停变蓝；出处 `.src`：白底细边行。

## 2.2 修订（2026-11-18 13:50，Rick：“字体不对”“边框丑”“直接抄 multica”）

**根因（对照 multica 截图查出来的）**
1. **字体是头号原因**：Inter 没打包，离线时拉丁/数字回退到系统字；中文在 Linux / 截图机上落到 Noto Sans CJK —— 这台机器上它只有 Regular 和 Bold 两档，所以凡是写 500/600 的地方都被渲染成 700 粗体，整屏发黑发笨。Mac 上是苹方，问题轻一些，但 600 的苹方中文也偏重。
2. **字重偏重**：标题、卡片标题、金额、KPI 用了 600。
3. **框太多**：结果列表每条都是“描边 + 阴影”的独立卡片，卡里还有描边的胶囊和输入框，框套框。
4. **灰字太浅**：12px 中文用 #8B8B94，糊。

**改法**
- 字体：自带 `assets/fonts/Inter-var.woff2`（70KB，拉丁子集）+ `NotoSansSC-var.woff2`（1.0MB，思源黑体可变字重 350–600，按全站用字 + GB2312 一级字子集化）。Mac/iOS 自动用 `-apple-system / PingFang SC`（`html[data-mac]`），其他系统用自带思源黑体，字重 400/500 都是真字重。
- 字重上限 500：`--fw-b` 改为 500，`b/strong` 500；数字/KPI 400。
- 灰字：`--text-3` #6F6F79（不浅于 multica muted-foreground）；最小 12px。
- 卡片：按 multica board-card —— 白底 + 1px #E4E4E7 + 极淡阴影，12px 圆角；选中 = 品牌蓝描边。
- **列表不再一条一框**：新增 `.rows` 容器（frame.css.tpl），把一串 `.card` 变成一张卡里用发丝线分隔的行；`.sect` / `.APP .sec` 变为 multica 式浅灰分组条（32px、8px 圆角）。
- 标签：胶囊（multica radius-label）。侧栏选中 = sidebar-accent #E9E9EB。
- 数值全部来自 multica 开源仓库 tokens.css，**手写实现、未复制其代码**（其许可证对 UI 代码有品牌保留与商业托管限制，见 style_ref/multica-src/NOTES-JK.md）。
- 已加 multica 式图标竖栏 rail（56px：对话 / 收件箱 / 搜索 / 知识库 / 技能 / 电脑 / 后台 / 演示，48px 项 + 11px 字，选中 = sidebar-accent），侧栏收窄到 216px；点 logo 收起/展开侧栏；≤1180px 只留竖栏。
- 提示条（toast）改到右上角（top 56 / right 20），不再盖住面板左上的返回链接和标题。
- 模拟政务网站在深色主题下保持浅色（computer/app.css 末尾），按钮不再变浅红。
