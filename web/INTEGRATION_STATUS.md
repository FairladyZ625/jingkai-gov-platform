## 怎么跑
- 双击 `index.html`；登录页点任一演示账号。
- 侧栏底部「一键演示」= 全功能自动走一遍（可暂停 / 下一段 / 退出）。
- 回形针 →「试试样例文件」可模拟拖入文件；也可直接把电脑上的文件拖到对话区。
- 头像菜单 → 切换视角 / 重置演示数据。
- 测试脚本：`node /workspace/jk/v4lead/smoke.js`（冒烟）、`node /workspace/jk/v4lead/e2e.js`（全量演示 + 布局检查）。
