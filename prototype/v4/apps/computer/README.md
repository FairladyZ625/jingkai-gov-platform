# 电脑操作（apps/computer）

AI 替你打开网页和业务系统，登录、填表、下载、查进度。**提交、签章、付款、验证码一律停下来等人确认**，每一步截图留档、写审计。

| 文件 | 作用 |
|---|---|
| `apps/computer/app.js` / `app.css` | 播放器：浏览器视窗、AI 光标、打字动画、步骤胶片、接管 / 暂停 / 停止 |
| `apps/computer/sites.js` | 被操作系统的模拟画面（统一身份认证、政策兑现平台、统计直报、官网通知） |
| `api/computer.js` | 接口适配：`JKApi.computer.*` |
| `mock/computer.js` | 演示后端：任务、系统授权、操作脚本、运行记录、人工确认 |

## 四个任务
| 任务 | 系统 | 停在哪 |
|---|---|---|
| 政策申报填表 | 经开区政策兑现综合服务平台 | 验证码（你输入）、“电子签章并提交”前 |
| 统计月报填报 | 统计联网直报平台 | 验证码、“上报”前 |
| 下载通知入知识库 | 经开区官网 · 通知公告（真实 144 条通知） | 入库前问一声 |
| 查询办理进度 | 政策兑现平台 · 我的申报 | 只读 |

- 申报内容来自企业台账（企业管理）；申报事项取真实“申报中”通知；金额标“AI 估算，请核对”。
- 敏感信息脱敏：信用代码、手机号、密码；截图中的密码 / 验证码同样遮盖。
- 系统授权页可关闭某系统；“提交 / 签章 / 付款 / 验证码必须人确认”这条规则不能关。
- 每次操作：步骤截图 + 日志 + 审计（`电脑操作`），可在“操作记录”回放。

## 对话怎么调
| 说法 | 结果 |
|---|---|
| 帮我把纸鹿二号智驾的申报表填了 | 选企业 → 登录 → 问验证码 → 填表上传 → 停在提交前，对话里点“确认提交”→ 拿到受理编号 |
| 帮我把纸鹿二号智驾的统计月报填了 | 同上，停在“上报”前 |
| 去官网把最新的申报通知下载下来存到知识库 | 找到最新通知 → 下载 → 问一声 → 存入知识库「政策库」 |
| 查一下纸鹿二号智驾的申报进度 | 登录 → 读取“我的申报” |

技能里也可加 `{ type: 'computer', task: 'stats' }` 步骤，运行后跳到这里接着做。其它模块：`ctx.nav.open('computer', 'run', { task: 'apply', ent: 'E002' })` 直接开始执行。

## 接口（api/computer.js）
`tasks · setSystem · match · runs · run · start · report · confirm`
- `start` 返回 `CuRun`：`{ id, task, title, system, ent, steps: [{ title, page, url, human?, ops: [...] }], fields, status }`。
- `confirm({decision:'approve'|'decline', kind})`：只有人点了才会提交；后端生成受理编号。

## 如何修改
- 任务、系统、停点：`mock/computer.js` 中 `TASKS`、`SYSTEMS`【可改】。
- 页面长相：`apps/computer/sites.js`（类名 `vs-*`，颜色跟随深 / 浅主题）。
- 正式版：用受控浏览器（如 Playwright 服务）执行同样的步骤脚本，把截图和日志回报到 `PATCH /api/apps/computer/runs/:id`；界面不用改。
